# Booking workspace design

Keep the Bookboll Payments visual language: navy background #0d1522, raised navy #172334, blue #4c8dff, pale text #edf3ff, muted text #9caec8, amber #e5aa42. Use the existing application sans-serif and tabular figures, with 26px page titles, 16px section titles and 12–14px table text.

Layout: left-aligned page header → persistent period/date-basis controls → compact activity summary → search and expandable advanced filters → records or charts. Booking time, court and customer lead each row; immutable creator and channel stay together. Money is labelled booking value, with links to Payments for actual receipts and allocations.

Principles: the same server query drives records, summaries, charts and export; membership calendar sessions and skipped-payment blocks are visibly distinct from bookings; every currency stays separate; saved source evidence takes precedence over legacy origin; date and scope changes never leave stale figures visible.

Brief review: retain the established Payments styling rather than introduce another dashboard theme. Avoid a decorative hero and redundant financial cards. The distinctive element is the operational booking row: reservation time beside court, customer and who entered it. Keep membership/event analytics accessible separately, without mixing subscription charges into court-booking counts.
